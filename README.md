# Arbeitszeit-Tracker

Eine kleine Web-App zum Erfassen der eigenen Arbeitszeit, die offline auf dem
Handy läuft und den Gleitzeit-Saldo im Blick behält. Sie rechnet die
gesetzlichen Pausenregeln automatisch ein und unterscheidet verschiedene
Tagesarten wie Büro, Homeoffice, Schule, Urlaub oder Krank.

Entwickelt mit reinem HTML, CSS und JavaScript (ohne Framework) als
installierbare PWA. Projekt im Aufbau.
